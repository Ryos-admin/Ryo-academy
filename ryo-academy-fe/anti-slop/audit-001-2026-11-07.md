## Numbered Findings List

### Finding 1 [HIGH]
- **Rule:** R-02 (Copywriting - Em Dash Character Ban)
- **Location:** `src/pages/fee-pages.tsx` (lines 205-207, 304, 350-353, 475, 616)
- **Reason:** Em dash character (`—`) is used as empty-data placeholder fallback text in table columns, descriptions, and detail lists instead of a hyphen (`-`) or `N/A`.

### Finding 2 [HIGH]
- **Rule:** R-02 (Copywriting - Em Dash Character Ban)
- **Location:** `src/pages/admissions-students-pages.tsx` (lines 539, 1270, 1523, 1529, 1630, 1737, 1771, 1981, 2226)
- **Reason:** Em dash character (`—`) is returned by `displayMoney(null)` and missing relation lookups across the admission and concession cockpit instead of a hyphen (`-`) or empty indicator.

### Finding 3 [HIGH]
- **Rule:** R-26 (Interactive Elements - Functional Completeness)
- **Location:** `src/pages/academic-pages.tsx` (line 2092)
- **Reason:** Cancel button handler references undeclared variable `id` (`onClick={() => setLocation(id ? ... : ...)}`), triggering an unhandled runtime ReferenceError on click.

### Finding 4 [HIGH]
- **Rule:** R-25 (Color Contrast - WCAG AA Standards)
- **Location:** `src/pages/admissions-students-pages.tsx` (line 1720)
- **Reason:** Setting `opacity-60` on excluded and inactive table rows drops `text-muted-foreground` below the required 4.5:1 WCAG AA contrast ratio against the table card background.

### Finding 5 [HIGH]
- **Rule:** R-03 (Mobile Responsiveness - Minimum Tap Targets)
- **Location:** `src/pages/fee-pages.tsx` (line 1045) and `src/pages/admissions-students-pages.tsx` (line 1816)
- **Reason:** Compact table action buttons (`h-8`, 32px height) do not meet the minimum 44px tap target size on touch/mobile viewports.

### Finding 6 [MEDIUM]
- **Rule:** R-28 (Accessibility - Assistive Technology Context)
- **Location:** `src/pages/fee-pages.tsx` (lines 1022, 1037)
- **Reason:** Multi-row checkboxes use generic `Mandatory` and `Discount applicable` labels without row-specific context for screen-reader users navigating multiple rows.

### Finding 7 [MEDIUM]
- **Rule:** R-26 (Interactive Elements - Error Resilience)
- **Location:** `src/pages/academic-pages.tsx` (line 402)
- **Reason:** `query.data?.school.name` accesses `.name` without optional chaining, creating an unhandled TypeError crash if `school` is null or undefined.

### Finding 8 [LOW]
- **Rule:** R-28 (Accessibility - Visible Focus States)
- **Location:** `src/pages/fee-pages.tsx` (line 1045)
- **Reason:** The row removal button lacks an explicit `focus-visible:ring-1` indicator when navigating through the table using the keyboard Tab key.
